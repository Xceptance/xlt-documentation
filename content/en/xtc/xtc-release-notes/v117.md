## Load Testing

### New Feature: Load Test Templates

We have introduced **Load Test Templates** to simplify setting up recurring load tests across your team.

- **Reusable Blueprints**: Define and maintain template configurations for machine setups, profiles, and properties without mixing them into your active test runs.
- **Dedicated Workspace**: Templates are organized in their own dedicated **Templates** section in the project navigation.
- **Seamless Conversion Workflows**:
  - **Create Template**: Turn any existing load test into a reusable template with a single click.
  - **Create Load Test**: Instantiate a ready-to-execute load test directly from any template.

### Code Archives

#### Increased Upload Limit

To better support test suites that bundle large test datasets or dependencies, the maximum upload size for code archives has been increased from 100 MB to **1 GB**. In addition, underlying network ingress and upload streaming have been optimized to handle large archive transfers reliably.

#### Improved Upload Feedback and Guidance

The code archive upload interface now includes a clear hint showing the 1 GB file size limit. Furthermore, error handling has been improved: if an upload fails or an archive exceeds the size limit, XTC now provides a specific, informative error message instead of a generic failure notice.

### AI Analysis

#### AI Usage Tracking

Resource usage tracking has been extended to record AI consumption at both the project and organization levels:

* **Project Level**: Every individual AI invocation is recorded with its input and output token counts, providing detailed, request-by-request visibility.
* **Organization Level**: AI usage metrics are aggregated per project, AI model, and month, giving administrators a clear monthly overview of organization-wide consumption.

In both the project and organization resource usage views, a new dedicated **AI** tab provides access to these tracked metrics.

#### Report Display Enhancements

The display and layout of generated AI analysis reports have been refined. Page width and table spacing have been improved to ensure complex analysis tables and structured summaries render cleanly and legibly.

### Machine Scaling with Load Factor

When configuring a load test with a custom load factor, you can now automatically scale the number of load generator machines alongside the test load:

* **Proportional Scaling**: In the load profile settings, enable the new **Also Scale Machines** option. XTC will then automatically adjust the configured machine count up or down proportionally based on the selected load factor.
* **Fraction Handling**: If proportional scaling results in a fractional machine count, XTC automatically rounds up to the next whole machine to prevent underscaling.
* **Transparent Visibility**: When this option is active, the calculated effective machine count is displayed as a read-only **Load Factor Scaled Machine Count** field on the **Machines** configuration tab. When disabled, this field remains hidden.

### Highlighting Comparable Reports

Reports marked as *comparable* are now visually highlighted directly in the reports table on the load test **Results** page. A dedicated comparison icon is displayed alongside the report entry (similar to the pin icon for pinned reports), making it easy to identify at a glance which reports are eligible for comparison and trend analysis.

### Updated XLT 10

We have updated XLT to version **10.0.0-beta-5** in both XTC and the XLT 10.x execution environment.

#### Reporting Enhancements in XTC

* **Enhanced AI Data**: Extended metrics and formatting in `ai-data.md` for AI-assisted analysis reports.
* **Test Evaluation Details**: Evaluation information maintained in XTC — such as the overall rating score, summary, and detailed evaluation — is now included in the rendered HTML report and the companion PDF report (if enabled).
* **PDF Report Generation**: Support for optionally generating a compact, archivable PDF report when creating the regular HTML report. The PDF contains only the most important data tables and charts.

To enable the creation of the optional PDF companion report, click the **New** button to create a new custom report, click **Show Advanced Settings** in the dialog, and then set the following property in the **Report Generator Properties** section:

```properties
com.xceptance.xlt.reportgenerator.pdf.enabled = true
```

Once the new HTML report is available, open it and click the **PDF** entry in the navigation bar to display the PDF report.

#### XLT 10.x Execution Environment

* **HtmlUnit 5.x Upgrade**: Upgraded HtmlUnit to version 5.x. Note that this upgrade may introduce minor API changes.

### REST API Enhancements

Several new endpoints and parameters have been added to the XTC REST API to support automated reporting workflows:

* **Create Report**: Creates a new load test report. The endpoint supports the `noRampUp` parameter to automatically exclude the ramp-up period and generate steady-state reports. It also supports `createPdf` to generate a streamlined companion report in PDF format alongside the standard HTML report.
* **Download AI Data**: A new endpoint allows downloading the structured `ai-data.md` file from a load test report, facilitating external evaluation or custom LLM-based analysis pipelines.
* **Download PDF Report**: You can now download the generated `load-report.pdf` file directly via the API (when generated with the `createPdf` option enabled).

For detailed request payloads and schema specifications, visit the [API Explorer](https://xtc.xceptance.com/exploreApi).

## Monitoring

### SMS Monitoring Alert Notifications Removed

As previously announced, the SMS notification channel has been deactivated. Monitoring alerts can be delivered via **push notifications**, **email**, or **Slack**.

If you have not already done so, please migrate any remaining notification lists to push notifications:

1. Refer to the [XTC v115 Release Notes]({{< relref "/xtc/xtc-release-notes/v115/#new-feature-push-notifications" >}}) for instructions on setting up push notifications via the ntfy app.
2. In your project notification lists, update user subscriber entries to enable the **Push Notification** channel.

{{% note notitle %}}
Phone numbers are still retained in user profiles for contact purposes, but phone number verification via SMS is no longer required.
{{% /note %}}


## Platform

### Post-Login Redirect After Session Timeout

When your session expires and you are prompted to log back in, XTC now automatically redirects you back to the page and view you were previously working on, preventing lost context and streamlining your workflow.

### Dismissible In-App Notifications

All in-app notification banners now include a close icon (`×`), allowing you to instantly dismiss notifications and immediately interact with underlying UI elements.
