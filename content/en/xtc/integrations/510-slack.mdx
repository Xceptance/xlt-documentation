XTC integrates with [Slack](https://slack.com) to send notifications about system events to designated channels. Notifications include status changes for load tests and monitoring incidents.

## Configuration

Configure Slack notifications at either the organization or project level.

:::info[Role Required]
To configure Slack integration on org level, your account must at least have the role of an [organization administrator](/xtc/basics/organizations/#user-roles-within-an-organization) within the organization.
::: 

:::info[Role Required]
To configure Slack integration on project level, your account must at least have the role of a [project administrator](/xtc/basics/projects/#user-roles-within-a-project) within the project.
:::

![Default configuration values at the organization level: message sending is off, the integration is unconfigured, and no target channels are set. Threads and compact messages are off.](/images/xtc/slack-config-readonly.png)
*Default configuration values at the organization level: message sending is off, the integration is unconfigured, and no target channels are set. Threads and compact messages are off.*

Organization settings apply to all member projects unless explicitly overridden. Overrides apply per setting: omitting a specific project value leaves the organization setting active.

## Configuration values

Clicking the edit button on the Slack configuration opens the settings form:

![The Slack integration config form](/images/xtc/slack-config.png)
*The Slack integration config form*

### Send messages

The Slack integration sends no messages unless enabled. Project settings always take precedence over organization defaults: if a project sets this to *Disabled*, it sends no messages even when the organization integration is active.

### Set up Slack integration

This action redirects the browser to Slack to start authorization. If your Slack account holds administrative permissions in the workspace, a confirmation screen asks you to approve the XTC app. Upon approval, Slack redirects back to XTC, where **Slack Integration** displays "Done" and **Slack Workspace** lists the connected workspace name.

![Slack integration installed into a workspace named "XTC-Test-Workspace"](/images/xtc/slack-config-token-installed.png)
*Slack integration installed into a workspace named "XTC-Test-Workspace"*
  
:::warning
Clicking the "Set Up Slack Integration" button redirects to Slack *without* saving other form edits.
:::
  
:::note
If your Slack workspace requires app approval, you might see a prompt requesting approval from a workspace administrator. Once approved, restart setup from the XTC configuration form.
:::

When configuring an integration at the project level, it overrides settings inherited from the parent organization.

### Remove Slack integration

Removing the integration from your organization or project clears all stored OAuth tokens and webhook settings. To re-enable the integration later, you must repeat the setup and authorization flow.

:::note
When removing an integration from a project, the parent organization's integration automatically takes effect. Projects cannot override organization settings with empty values.
:::

### Target channels

Specify the Slack channels where notifications should post. Separate channel names with spaces. This setting overrides inherited organization channels when defined.
  
:::note
XTC does not support sending notifications to individual users or private channels.
:::

### Message grouping and compact view

Default Slack messages display detailed metrics. To optimize channel space, choose _Compact Message View_ or _Group related messages into threads_:

![Default message format with thread for follow-up messages about the same load test.](/images/xtc/slack-format-thread.png)
*Default message format with thread for follow-up messages about the same load test.*

![A message in compact format.](/images/xtc/slack-format-compact.png)
*A message in compact format.*

### Send test message

Once configuration is complete (either inherited or configured locally), administrators can dispatch a test message to verify connectivity. Check your Slack channel to confirm delivery.

## Notification events

:::warning
Due to Slack rendering constraints, XTC strips Markdown formatting characters (`_`, `*`, `` ` ``, `~`) from organization, project, load test, and report titles before sending messages.
:::

When enabled, XTC dispatches notifications for the following events:

### Load tests
* **Start**: a user starts a load test from the UI.
* **Running**: the setup phase completes and test scenarios start executing.
* **Finished**: the test run completes successfully.
* **Aborted**: a user aborts the test run early.
* **Error**: a step in the load test encounters a fatal error.
* **Report available**: the final HTML or PDF performance report is ready.

XTC also dispatches notifications when intermediate reports become available during execution.

### Monitoring

When a monitoring scenario includes a Slack subscriber in its [notification list](/xtc/monitoring/monitoring-configuration/#defining-a-notification-list), XTC dispatches incident alerts directly to the designated channel.
