A load test project in XTC can contain any number of XLT load and performance tests. You can easily track configurations, applied load, and test outcomes in a single unified view.

## Load tests overview

:::info[Role Required]
To use this feature, your account must at least have the role of a [reviewer](/xtc/basics/projects/#user-roles-within-a-project) within the project.
:::

Select **Load Tests** in the left sidebar to open the load tests overview. The table displays all configured load tests in the project alongside their current execution status:

* _New_: newly created tests that have not run yet
* _Running_: tests actively executing on agent machines
* _Finished_: completed test runs
* _Aborted_: tests terminated early by a user
* _Error_: tests that stopped due to a technical error

The table also displays the start date, execution duration, scorecard summary rating, and an actions context menu.

![The load tests overview of a project.](/images/xtc/loadtests_table.png)
*The load tests overview of a project.*

Select any test name in the table to open its detail view. The view organizes test information across six tabs:

* **Status**: displays real-time [test status](/xtc/loadtesting/monitor-lt/#test-status) and execution stage progress.
* **Settings**: configures [test properties](/xtc/loadtesting/lt-settings/), repository branch overrides, and assigned agent machines.
* **Scenario Status**: displays individual [test scenario execution statuses](/xtc/loadtesting/monitor-lt/#scenario-status), active users, and error counts.
* **Results**: stores downloaded [test results](/xlt/advanced/results/) and intermediate metrics captured during execution.
* **Reports**: lists generated [test reports](/xlt/manual/reports/) with options to view, share, or download them.
* **Evaluation**: captures rating scores, summary notes, and detailed [evaluations](/xtc/loadtesting/evaluation/).

### Color groups

You can assign custom background colors to individual load tests in the table to group related runs or highlight important test results.

![Custom color highlighting on test rows](/images/xtc/loadtest_colors1.png)
*Custom color highlighting on test rows.*

To assign a color, open the _Edit Description_ dialog from the test's context menu and choose the desired color. To restore the default background, clear the color selection.

![Color selection palette in the test description dialog](/images/xtc/loadtest_colors2.png)
*Color selection palette in the test description dialog.*

### Deleting load tests

To delete a single load test, choose _Delete_ from its context menu.

To delete multiple load tests at once, select their checkboxes in the left column and click _Delete_ at the top of the table.

![Bulk deletion of selected load tests](/images/xtc/loadtest_bulkDelete.png)
*Bulk deletion of selected load tests.*

A confirmation dialog prompts you to review and confirm the selection before deletion proceeds.

If you delete a load test by mistake, you can restore it within 30 days. Open the table menu (three dots), select _Show Deleted Items_, and click _Undo Deletion_ in the context menu of the target test. To return to active tests, select _Hide Deleted Items_.
