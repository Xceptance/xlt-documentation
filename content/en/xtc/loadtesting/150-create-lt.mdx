## Creating a New Load Test

:::info[Role Required]
To create a load test, your account must at least have the role of a [tester](/xtc/basics/projects/#user-roles-within-a-project) within the project.
:::

To create a new load test, navigate to the _Load Tests_ overview of your load test project. You can choose from three options:

1. **Create from Template (Recommended)**: Instantiate a pre-configured test setup directly from a [Load Test Template](/xtc/loadtesting/templates/).
2. **Duplicate an Existing Run**: Clone an existing test run and adjust its settings.
3. **Create from Scratch**: Create a fresh test setup with default parameters.

![Create a new load test or duplicate an existing one.](/images/xtc/loadtest_newOrDuplicate.png)
*Create a new load test or duplicate an existing one.*

You will be prompted to enter a name and description for the new load test. The test status will be _New_.

You can then enter the configuration by clicking the name of the newly created test, which will take you to the [settings of this test](/xtc/loadtesting/lt-settings/).
