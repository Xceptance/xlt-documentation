XTC provides multiple views for tracking load tests in progress. While comprehensive execution data is compiled into the final report, real-time metrics provide immediate insight into running tests.

:::info[Role Required]
To view the load test and scenario status, your account must at least have the role of a [reviewer](/xtc/basics/projects/#user-roles-within-a-project) within the project.
:::

## Test status

The _Status_ tab tracks progress through each test phase: preparation, execution, and cleanup. Steps update as execution proceeds.

![The status view for a running load test.](/images/xtc/loadtest_status.png)
*The status view for a running load test.*

If a step fails (due to timeouts or failed authentication), the tab flags the failure so you can identify why execution halted.

## Scenario status

The _Scenario Status_ tab populates while the test runs or after it finishes. Below the [live metrics](#live-metrics) graph, a table details each scenario, showing execution status, active user counts, average runtimes, event counts, and errors:

![The scenario status view for a running load test.](/images/xtc/loadtest_scenarioStatus.png)
*The scenario status view for a running load test.*

### Live metrics

The graph above the table updates live during execution, displaying active users alongside the configured user limit for each scenario. Hovering over the graph reveals instantaneous values (with the user limit in parentheses).

Use the scenario dropdown to **filter** the view to specific scenarios or show aggregate totals. To expand vertical resolution, select a higher **scaling factor**.

Red vertical bars mark scenario errors. These markers bind to individual scenarios: selecting a specific scenario highlights only its errors, while selecting _Total_ plots cumulative errors.

:::note
Occasional gaps in live metrics can occur if the status polling service restarts or cannot reach the agent controllers. Test execution continues normally during these intervals.
:::

Live scenario metric charts remain available for 7 days after the test run finishes.

## Error reporting

XTC displays error and event logs from your load test while it runs. This enables diagnosing errors without having to generate an interim load test report.

To view runtime errors and events, open the *Error Reporting* tab on the load test details page. Select a time window and apply search filters to isolate entries. Expand any error entry to inspect its stack trace.

![Live error reporting during a test run.](/images/xtc/loadtest_error_reporting.png)
*Live error reporting during a test run.*

XTC stores live error and event data for **24 hours**.

:::note
This feature is experimental and enabled for selected organizations.
:::
