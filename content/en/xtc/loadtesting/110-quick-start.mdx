:::info[Role Required]
To start, stop, and abort load tests, your account must at least have the role of a [tester](/xtc/basics/projects/#user-roles-within-a-project) within the project.
:::

## How to run a predefined load test

As a tester, you can start, stop, and review configured load tests in XTC. This guide provides a quick overview of running a load test, with links to detailed documentation for each stage.

### Navigate to the load test

Navigate to the [load tests overview](/xtc/loadtesting/overview/) by selecting **Load Tests** in the left menu and locate the load test you want to run (marked with status _New_ if not yet executed). Click the test name to view details.

If you received a direct link to the test, opening the _Status_ tab displays: "This load test was not started yet."

### Start the load test

To start the prepared load test, select _Start_ from the load test table context menu or click the _Start_ button on the details page:

![Start or schedule the configured load test via context menu.](/images/xtc/loadtest_start1.png)
*Start or schedule the configured load test via context menu.*

![Start or schedule the configured load test on the test page.](/images/xtc/loadtest_start2.png)
*Start or schedule the configured load test on the test page.*

Confirm the prompt to proceed with the specified settings. Clicking _Start Load Test_ initiates execution: XTC checks out the repository commit, compiles the test project, provisions the requested agent machines, and executes the test scenarios for the scheduled duration.

### Monitor the load test

Once started, track progress on the [**Status**](/xtc/loadtesting/monitor-lt/#test-status) tab. Steps update to _done_ or _failed_ as execution proceeds.

![The status view for a running load test.](/images/xtc/loadtest_status.png)
*The status view for a running load test.*

The [**Scenario Status**](/xtc/loadtesting/monitor-lt/#scenario-status) tab displays metrics while the test runs or after it finishes. This view lists all active scenarios alongside state indicators, active user counts, average runtimes, events, and error counts:

![The scenario status view for a running load test.](/images/xtc/loadtest_scenarioStatus.png)
*The scenario status view for a running load test.*

### Finish the load test

Load tests **stop automatically** once the scheduled duration completes. XTC deprovisions the agent machines, downloads [results](/xlt/advanced/results/), and generates a [test report](/xlt/manual/reports/).

To stop an active test early, click _Abort Load Test_ in the top-right corner.

![Abort the load test.](/images/xtc/loadtest_abort_click.png)
*Abort the load test.*

### Load test reports

XTC automatically [generates a report](/xlt/manual/test-evaluation/) when the load test finishes. The generated report appears on the _Reports_ tab. You can inspect reports directly in the browser or download them as compressed archives.

### Rerun the same load test

To rerun a test with identical settings, XTC allows duplicating existing tests. Navigate to the _Load Tests_ overview of your project and select _Duplicate_ from the test context menu:

![Duplicate an existing load test.](/images/xtc/loadtest_duplicate.png)
*Duplicate an existing load test.*

You can then start, monitor, and complete the duplicated test as described in [Start the load test](#start-the-load-test).
