XTC provides a number of keyboard shortcuts to help you navigate and perform actions quickly without reaching for the mouse.

:::tip[Quick In-App Reference]
Press the <kbd>?</kbd> key anywhere in XTC to open an overlay displaying all available hotkeys.
:::

## Global Navigation & Interface

These shortcuts are available across the entire XTC application:

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>?</kbd> | Show Shortcuts | Displays the overlay list of all available hotkeys. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>H</kbd> | Go to Dashboard | Returns to your personal home dashboard from anywhere in XTC. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>O</kbd> | Select Organization | Activates the organization dropdown in the header. Use <kbd>↑</kbd>/<kbd>↓</kbd> to highlight an organization and press <kbd>Enter</kbd> to select it. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> | Select Project | Activates the project dropdown in the header. Use <kbd>↑</kbd>/<kbd>↓</kbd> to highlight a project and press <kbd>Enter</kbd> to select it. |

## Dialogs and Forms

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> | Confirm / Submit | Submits the active modal, dialog, or form (such as the *Schedule Load Test* dialog). |
| <kbd>Esc</kbd> | Cancel / Close | Closes the open dialog or cancels the current modal action. |

:::note[Form Submission]
Standard <kbd>Enter</kbd> alone is intentionally not supported to submit forms, as it is often needed to interact with the currently focused input element (e.g., multiline inputs or search fields). Use <kbd>Alt</kbd>+<kbd>Enter</kbd> instead.
:::

## Load Testing

The following shortcuts are available on the details page of a load test:

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>Ctrl</kbd>+<kbd>Left</kbd> | Previous Load Test | Navigates to the previous load test in the project. |
| <kbd>Ctrl</kbd>+<kbd>Right</kbd> | Next Load Test | Navigates to the next load test in the project. |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd> | Start Load Test | Starts execution of the currently displayed load test. |
