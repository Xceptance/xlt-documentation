## Prerequisites

Before installing XLT, verify that your development machine meets the following requirements:

* **Java 21 or higher**: Verify with `java -version`.
* **Hardware**: 2+ CPU cores, minimum 4 GB RAM, and 1 GB available disk space.
* **Modern Web Browser**: Firefox, Chrome, Edge, or Safari with JavaScript enabled to view HTML test reports.

## Quick Setup

### Step 1: Download & Extract

1. Download the latest XLT distribution archive from the [Xceptance Download Page](https://www.xceptance.com/en/xlt/download.html).
2. Extract the archive to your preferred directory (for example, `~/tools/xlt`):

```bash
unzip xlt-10.*.zip -d ~/tools/
```

### Step 2: Verify Java Environment

Ensure JDK 21 is configured in your system `PATH`:

```bash
which java
java -version
```

### Step 3: Verify the Installation

Navigate to the `bin/` directory and test the Master Controller CLI:

```bash
cd ~/tools/xlt-*/bin
./mastercontroller.sh -help
```

If the command displays the available command-line options, your XLT installation is ready.

:::info[Maven Integration]
If you build test suites using Maven rather than the standalone CLI, add the XLT dependency with `provided` scope as shown in the [Manual Installation Guide](/xlt/manual/installation/#option-2-maven-dependency).
:::

Proceed to [Setting Up the Demo Application](/xlt/quick-start/demo-application/) to configure your first test target.
