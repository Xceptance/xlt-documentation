## Generate the Test Report

Upon test completion, generate the HTML load test report from the collected measurement directory:

```bash
cd <xlt>/bin
./create_report.sh ../results/20261020-120000
```

Open the generated report in any modern web browser:

```bash
xdg-open ../reports/20261020-120000/index.html
```

:::note[Customizing Reports]
To configure custom percentiles, chart colors, or error thresholds, see [Report Options](/xlt/manual/report-options/) and [Report Configuration](/xlt/manual/report-configuration/).
:::

## Key Report Sections

The generated report contains interactive tables and time-series charts organized into dedicated sections:

* **[Overview](/xlt/manual/test-evaluation/#overview)**: Summary metrics, total requests, concurrent user progression, and error counts.
* **[Transactions](/xlt/manual/test-evaluation/#transactions)**: End-to-end execution times, pass/fail ratios, and percentiles for each test scenario.
* **[Actions](/xlt/manual/test-evaluation/#actions)**: Performance breakdown for individual user steps (e.g. `Search`, `AddToCart`).
* **[Requests](/xlt/manual/test-evaluation/#requests)**: HTTP-level metrics including DNS lookup, connect time, time-to-first-byte (TTFB), and transfer duration.
* **[Network](/xlt/manual/test-evaluation/#network)**: Bandwidth utilization, response status code distributions (2xx, 3xx, 4xx, 5xx), and target host breakdown.
* **[Page Load Timings](/xlt/manual/test-evaluation/#page-load-timings)**: Navigation timing and Core Web Vitals collected during real-browser WebDriver runs.
* **[Errors](/xlt/manual/test-evaluation/#errors)**: Categorized error logs, failed request URLs, and linked [Result Browsers](/xlt/manual/result-browser/) capturing full DOM snapshots at the exact moment of failure.
* **[Agents](/xlt/manual/test-evaluation/#agents)**: Load generator host health metrics (CPU utilization, memory consumption, JVM garbage collection pauses).

For detailed interpretation strategies and diagnosing performance bottlenecks, proceed to [Test Evaluation](/xlt/manual/test-evaluation/).
