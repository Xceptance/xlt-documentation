## System Requirements

### Hardware

* **CPU**: 1.5 GHz or higher (multi-core recommended for load generators)
* **Memory**: Minimum 4 GB RAM (8 GB or more recommended for agents)
* **Disk Space**: 1 GB available disk space (installation requires ~150 MB; test results and result browsers require additional capacity depending on test duration and load)

### Software

* **Operating System**: Linux, macOS, or Microsoft Windows.
* **Java Virtual Machine**: Java 21 or higher (OpenJDK, Eclipse Temurin, Amazon Corretto, or Oracle JDK).
* **Web Browser**: Any modern browser (Firefox, Chrome, Edge, Safari) with JavaScript enabled to view HTML test reports and Result Browsers.

## Installation Methods

### Option 1: Archive Download

1. Download the latest XLT distribution archive from the [Xceptance website](https://www.xceptance.com/en/xlt/download.html).
2. Extract the archive to your desired directory. Avoid directory paths containing spaces.
3. Verify that Java 21 is available on your system `PATH`:

```bash
java -version
```

:::note[Java Runtime Requirement]
Ensure the `bin` directory of your JDK 21 installation is configured in your `PATH` and `JAVA_HOME` environment variables so XLT start scripts locate the runtime.
:::

### Option 2: Maven Dependency

To integrate XLT framework classes into Maven-based test suites, add the XLT dependency with `provided` scope:

```xml
<dependencies>
    <dependency>
        <groupId>com.xceptance</groupId>
        <artifactId>xlt</artifactId>
        <version>10.0.0-beta-5</version>
        <scope>provided</scope>
    </dependency>
</dependencies>
```

:::info[Release Status]
XLT 10 is currently in active preview (`10.0.0-beta-5`). If you require the previous general availability release, use version `9.2.1`.
:::

## Upgrading XLT

When upgrading to a new XLT version:

1. **Back up existing data**: Preserve custom configurations, results, and test suites:
   * Test suites (if stored inside the `<xlt>` directory)
   * Stored test results (`<xlt>/results/`)
   * Generated reports (`<xlt>/reports/`)
   * Custom agent and controller configurations (`<xlt>/config/*.properties`)
2. **Extract the new release**: Unpack the new XLT archive alongside the existing installation.
3. **Synchronize configuration**: Review changes in `config/default.properties` from `samples/testsuite-template` and copy any newly introduced settings into your test suite's `config/` directory.
4. **Update agent machines**: Ensure all distributed agent controllers run the identical XLT version as your local development and controller environment.

## Uninstallation

To uninstall XLT:

1. Back up any test results or reports you wish to keep.
2. Remove the XLT installation directory from your file system.
